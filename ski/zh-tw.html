🔁 第一原理：一個閉環，沒有主動被動

簡化：把整個人當成沿著板的路線走。轉彎需要的向心力，腳生不出來，只能來自雪：F·Δt = Δp。人只是給輸入（傾、壓、扭），板的 sidecut 決定弧線，雪推回來的力改變動量，身體再對位去承受這股力，而身體位置又變成下一個輸入。3D 裡：青 = p 動量、綠 = Δp（¼ 秒）、橙 = 物理要求的雪力、紫 = 身體排列；橙紫重疊 = 平衡。

⚖️ 重心在哪裡？

黃色球 = 重心（CoM），大約在肚臍後面、骨盆中間。直線 = 重心沿身體傾斜方向落到雪面，圓圈是落點（綠＝正確、橙＝開始偏、紅＝偏掉）：應該在雙腳附近、腳掌中間。

拉到兩邊試試：人偶、軌跡和肌肉都會跟著變，和上面「站姿」按鈕一樣。

怎麼找到自己的重心（在家／雪上練習）
  1. 穿著雪鞋站好，膝蓋腳踝微彎，前後慢慢搖：搖到腳跟或腳趾都會覺得快跌；中間最穩的那一點就是正確位置（腳掌中間、脛骨輕貼鞋舌）。
  2. 閉上眼再搖一次，專心感受腳底壓力從腳跟移到腳趾。
  3. 原地輕輕跳一下：落地不用扶、不會往後坐，就是重心在正確位置。
  4. 滑行時雙手放在前面看得到的位置；手掉到後面，多半就是坐後了。
  5. 在平地直滑時輕輕抬起一支板尾（板頭仍貼雪）：坐後的話抬不起來。

為什麼內腳也在出力？ ① 內腳仍然承受大約 10–40% 體重（雪況越硬、立刃越大，比例越高）；② 要讓內腳收短，股四頭肌要離心收縮、慢慢放，不是完全放鬆；③ 膕旁肌、髖屈肌負責把內腳拉後、拉高，讓雙腳前後一致；④ 脛前肌要拉住內腳鞋舌，不讓內腳後坐；⑤ 關節周圍肌肉協同收縮，保持膝蓋穩定，萬一外腳打滑也撐得住。所以外腳出主力，內腳負責「調節和保險」。

發力類型是由模型關節角度的變化算出來的：肌肉變長又在出力 = 離心收縮，變短 = 向心收縮，幾乎沒變 = 等長收縮。

板子 R = 側切半徑（板身上寫的 R 數字）。刻滑時轉彎半徑 ≈ R × cos(立刃角度)，傾倒角由 tan θ = v² / (g·r) 算出，所以速度、R、立刃三者互相牽動。這是理想化公式，實際上板子會彎得更深、雪會被壓實，所以實際可以刻滑得快一點。建議範圍是一般經驗值，不是硬性規定。
